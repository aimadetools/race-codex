How to decide fast

  1. If the facts are scattered, start with the inventory workspace.
  2. If one live questionnaire row is blocking the deal, start with the starter pack or builder.
  3. If the wording already exists but the buyer wants proof, named owner, or review date behind it, open the evidence map before you widen the packet.
  4. If the same questions keep returning, move the approved wording into the answer bank.
  5. If the reviewer is asking what an AI agent can access or change, route that thread into the dedicated AI agent review page.
  6. If the reviewer named OpenAI directly, use the OpenAI template, example, or comparison page before falling back to the generic route.
  7. If the thread already widened into procurement, counsel, or evidence cleanup, switch to the packet guide or review pack.
