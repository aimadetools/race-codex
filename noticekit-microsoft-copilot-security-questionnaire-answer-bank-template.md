# Microsoft Copilot Security Questionnaire Answer Bank

Use this file when buyers keep naming Microsoft Copilot, Copilot Studio, or Azure OpenAI directly across multiple deals. Keep one row per recurring question, preserve the named-vendor workflow, approval boundary, proof links, and flag anything that still needs procurement, privacy, security, or counsel review.

## Usage Notes

- Keep answers operational and specific to the Copilot-backed workflow in scope.
- Do not store secrets or customer data here.
- Keep short answer and long answer variants separate.
- Add proof links for every retention, training, scope, action-boundary, or notice claim that a buyer may challenge.
- Mark answers as `approved`, `needs review`, or `do not use`.
