# AI Security Questionnaire Answer Bank

Use this file as the reusable source of truth for repeated AI procurement and security-review questions. Keep one row per recurring question. Link proof, preserve owner notes, and flag anything that still needs counsel, privacy, or security review.

## Usage Notes

- Keep answers operational and specific.
- Do not store secrets or customer data here.
- Keep short answer and long answer variants separate.
- Add proof links for every claim that a buyer may challenge.
- Mark answers as `approved`, `needs review`, or `do not use`.
