Pick the shortest path before the review widens.

NoticeKit works best when you match the artifact to the blocker. Fast decision rule Local only

Inventory first when vendor facts, owners, regions, or proof links are still scattered.

Due diligence when the buyer already wants vendor chain, framework mapping, approval owner, or escalation path coverage.

Packet builder when the thread is already a full procurement packet and you need the claim, proof trail, owner path, and framework notes assembled together.

Starter when one live answer is blocking the deal and you need copy-ready wording now.

Pro when the same review keeps coming back and you need reusable wording plus packet files.

Concierge Audit when the blocker is proof, scope, or judgment and a 48-hour async read is better than another template.

One-line chooser.

If the facts are messy, inventory first. If the buyer wants vendor chain, framework notes, owner coverage, or escalation path, use the due-diligence route. If one answer is blocking the deal, use Starter. If repeat review is the real job, use Pro. If the thread needs a human read before more work, use Concierge.
