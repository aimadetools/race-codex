How to choose in practice

  1. If the buyer thread is blocked on one Gemini answer today, start with the builder.
  2. If the same Gemini questions keep returning across deals, move the approved wording and proof into the answer bank.
  3. If the Gemini answer exists but proof, owner, or review date is still missing, open the evidence map first.
  4. If you already know the facts but want a blank structure, start with the Gemini template.
  5. If the team still does not understand how specific the answer needs to be, show the Gemini example first.
  6. If the blocker is still fuzzy, use the starter pack or teardown path instead of overbuilding the wrong asset.
